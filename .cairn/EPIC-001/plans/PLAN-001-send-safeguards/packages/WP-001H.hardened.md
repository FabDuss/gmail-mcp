#### The modules and what a caller may ask

- **The session agent, `GmailMCP`.** A client lists each tool with the name, description and input schema it registered with. A read tool carries `readOnlyHint: true`; an undoable write `readOnlyHint: false` and `destructiveHint: false`; a destructive or sending tool `readOnlyHint: false` and `destructiveHint: true`. No tool carries `idempotentHint` or `openWorldHint` (DEC-002). `registerByKind` is the one registration method, and its interface stays as it is.
